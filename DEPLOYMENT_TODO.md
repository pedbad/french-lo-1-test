# Deployment Guide

## Overview

This is a React + Vite SPA. The build system automatically generates per-route
`index.html` files for every learning object slug (e.g. `dist/first-contact/index.html`),
so Apache can serve deep links without `mod_rewrite` or `.htaccess`.

There are **two servers**, each requiring its own build:

| Server | URL base path | Build command |
|--------|--------------|---------------|
| lcdev (dev/staging) | `/projects/french-basic/` | `bun run build:server` |
| lcitc (production) | `/french/french-basic/` | `bun run build:live` |

The debug sandbox (`debug-sandbox.html`) is available on lcdev only. Use the `with-debug`
variant for lcdev and the plain variant for lcitc:

| Server | With debug sandbox | Without |
|--------|-------------------|---------|
| lcdev  | `bun run build:server:with-debug` | `bun run build:server` |
| lcitc  | — | `bun run build:live` |

## One-time setup (developer machine)

1. Install Node 20+: https://nodejs.org/en/download/
2. Install Bun: https://bun.sh
3. Clone the repo
4. Install dependencies:
   ```bash
   bun install
   ```
5. Set up git pre-commit hooks (one-time per clone):
   ```bash
   bash scripts/setup-githooks.sh
   ```

## Deploying to lcdev (dev/staging server)

### Step 1 — Pull latest code

```bash
git pull origin main
```

### Step 2 — Install dependencies

```bash
bun install
```

### Step 3 — Build for lcdev

With debug sandbox (recommended for lcdev):
```bash
bun run build:server:with-debug
```

Without debug sandbox:
```bash
bun run build:server
```

### Step 4 — Verify the build output

Check that these files exist in `dist/`:
- `dist/index.html`
- `dist/src/main.js`
- `dist/src/client.css`
- `dist/first-contact/index.html` ← generated by build
- `dist/about-me/index.html` ← generated by build
- (one folder per LO slug — 15 total)
- `dist/debug-sandbox.html` ← only present with `with-debug` build

```bash
ls dist/
ls dist/first-contact/
```

### Step 5 — Deploy to lcdev

```bash
rsync -av --delete dist/ user@lcdev:/var/www/html/projects/french-basic/
```

Replace `user@lcdev` with the actual server hostname/user.

### Step 6 — Smoke test

- [ ] Landing page loads: `/projects/french-basic/`
- [ ] LO deep link loads directly: `/projects/french-basic/first-contact/`
- [ ] Refresh works on a deep link
- [ ] Debug sandbox loads: `/projects/french-basic/debug-sandbox.html`
- [ ] No 404 or console errors in browser
- [ ] At least one audio clip plays

## How slug routing works (no mod_rewrite needed)

The `generateSlugRoutes` Vite plugin (in `vite.config.js`) runs automatically after every
build. It reads `src/index-fr.json`, then copies `dist/index.html` to
`dist/<slug>/index.html` for each of the 15 learning objects.

When a user navigates to `/french/french-basic/first-contact/`, Apache finds the real file
`dist/first-contact/index.html` and serves it. React Router then reads the URL and renders
the correct LO. No `.htaccess` or `mod_rewrite` required.

If you add a new LO in future, add its slug to `src/index-fr.json` and the next build will
automatically create its route directory.

## Common mistakes

| Mistake | Symptom | Fix |
|---------|---------|-----|
| Used `build:server` for lcitc | Assets 404 (wrong base path baked in) | Run `build:live` for lcitc |
| Used `build:live` for lcdev | Assets 404 (wrong base path baked in) | Run `build:server` for lcdev |
| Used `build:*:with-debug` for lcitc | Debug sandbox accessible on production | Use `build:live` (no debug) |
| Deployed without running build | Stale JS/CSS served | Always build before deploying |
| Partial rsync (no `--delete`) | Old slug folders or stale chunks linger | Use `rsync --delete` |

## Troubleshooting

**Landing page works but `/first-contact/` returns 404**
- The slug directory wasn't generated. Rebuild — it may have used an old build artifact.
- Confirm `dist/first-contact/index.html` exists before deploying.

**Browser console shows `Unexpected token <` for JS files**
- A JS file request is returning HTML (the index page). Base path is wrong — you used the wrong build command for this server.
- Rebuild with the correct command and redeploy.

**All assets 404**
- Base path mismatch. Check which server you're deploying to and use the matching build command.
- Open `dist/index.html` locally and check the `src=` paths — they should start with `/projects/french-basic/src/` (lcdev) or `/french/french-basic/src/` (lcitc).

**Audio clips 404**
- Audio files live in `public/audio/` and are copied to `dist/audio/` by Vite. Confirm the rsync included the full `dist/` tree and that `dist/audio/` was not excluded.
