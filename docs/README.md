# Docs Index

Only these markdown files remain at repository root:

- `README.md`
- `CHANGES.md`
- `AGENTS.md`

All other project documentation is grouped under `docs/`:

- `docs/deployment/`
  - deployment, Apache, and server routing notes
- `docs/audio/`
  - audio migration maps, blockers, and audio TODOs
- `docs/grammar/`
  - grammar refactor plans/checklists
- `docs/pronunciation/`
  - pronunciation architecture notes and checklists
- `docs/a11y/`
  - semantic DOM audits, accessibility issues, and table audit notes
- `docs/styling/`
  - SCSS/Tailwind, color, typography, and image migration plans
- `docs/components/`
  - component-specific refactor plans/checklists
- `docs/process/`
  - project process notes, future project blueprint, and task trackers

Use this structure for new docs to keep repository root clean.
