# Teacher Audio Amends

This file tracks lesson-level audio issues and new recording requests raised during teacher review.

Status labels:

- `Needs review` - existing audio should be checked and likely re-recorded
- `Needs new audio` - new audio file is required and does not yet exist
- `Done` - issue resolved
